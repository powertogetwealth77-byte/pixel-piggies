# Pixel Piggies — MVP Screen Flow

## First-time player

Launch → Privacy-safe initialization → Title reveal → Level 1 → Win/Bloom Burst → Reward → Level 2

Do not place a store, ad, notification prompt, ATT prompt, account prompt, or daily reward between initial launch and the first completed level.

## Returning player

Launch → Daily delivery if eligible → Bloom Trail → Play → Results → Next level

## Primary navigation

- Piggie Market
- Bloom Trail
- Piggie Collection
- Settings from the map header

The center navigation action is always Play/Continue.

## Gameplay HUD

Top:

- Pause
- Level number
- Bloom Coins only if needed

Center:

- Pixel board
- Bloom Conveyor and capacity state

Bottom:

- Five Flower Pods
- Visible piggie queue
- Three Piggie Power buttons after introduction

Remove permanent shop buttons from active gameplay. Monetization should never obscure the puzzle.

## Results screen hierarchy

1. Animated completed artwork
2. Stars and Perfect Flow
3. Coins and fragments
4. Collection progress
5. Large Next Level button
6. Optional double-reward video
7. Small return-to-map action

## Failure screen hierarchy

1. Clear failure cause
2. Board still visible
3. Contextual hint
4. Retry
5. Optional rescue
6. Map exit

## Store

Featured → Piggie Powers → Collections → Bloom Coins → Free Rewards

Do not show six coin packs above the useful starter offers. The first screen should answer: “What helps me enjoy the game now?”

## Settings

- Music
- Sound effects
- Haptics
- Reduced motion
- High contrast
- Color symbols
- Language
- Notifications
- Privacy
- Support
- Restore Purchases
- Data request/delete pathway when applicable

## Required empty/error states

- No internet
- Ad unavailable
- Purchase pending
- Purchase failed
- Restore completed/nothing found
- Save conflict
- Content download unavailable
- Maintenance configuration
